* Neural network example

- What is a neural network?[fn:1]
  #+begin_quote
  An [artificial] neural network (ANN) is a function y = f[x,\phi] that
  maps multivariate inputs x = {x_1, x_2,....} to multivariate outputs y
  = {y_1, y_2,...} with parameters \phi = {\phi_1, \phi_2,...}. y = f[x,\phi] is a
  vector equation which (via the parameters) involves matrix
  multiplication.
  #+end_quote

- How is this different from linear regression?
  #+begin_quote
  It is not - at first. But we're doing something different with the
  parameters to introduce more flexibility. 
  #+end_quote

- Example network:
  1) scalar input x (that's where data come in)
  2) scalar output y (that's our prediction)
  3) parameters \phi = {\phi_0, \phi_1, \phi_2, \phi_3, \theta_10, \theta_11, \theta_20, \theta_21, \theta_30, \theta_31}
     (that's the knobs we can tune in advance = hyperparameters)
  4) dependencies in the form of a function:
     #+name: NN
     #+begin_quote
     y = f[x,\phi] = \phi_0 + \phi_1 a[\theta_10 + \theta_11 x] // \phi_1 * h_1
                     + \phi_2 a[\theta_20 + \theta_21 x]
                     + \phi_3 a[\theta_30 + \theta_31 x]
     #+end_quote

- Break it down by terms:
  #+begin_quote  
  1. f[x,\phi] is a function in one variable; it sums up three *linear*
     functions of the input data, each of the form \theta_i0 + \theta_i1 x.
  2. The three linear functions are passed through a filter in the
     form of an *activation* function a[]. This function can switch a
     term on (activated) or off (deactivated).
  3. The three resulting activations have *weights* \phi_i. They are summed
     and added to an offset \phi_0.
  #+end_quote     
 
- How is this a network?
  #+begin_quote
  Because it is not a pipeline (sequential flow) but a computational
  graph with branches to three parallel processes and a merge back:

  1. One input x *fans out* into three parallel, independent
     linear computations.
  2. Each computation goes through its own *activation*
  3. All three *fan back in* to a single output via a weighted sum.

  A network is a *directed acyclic graph* (DAG) of nodes connected by
  edges where edges correspond to parameters.[fn:2]
  #+end_quote

- Do you have to have at least 10 parameters?
  #+begin_quote
  No, that's a design choice - in this case, D = 3 *hidden units* (the
  linear functions \theta_i0 + \theta_i1 x). For D = 2 you get 7 parameters, and
  D=1 is the case of linear regression.
  #+end_quote

* ReLU activation function

- To switch a term on and off, the activation function must be a step
  function: a[z], also called ReLU (rectified linear unit) is zero for
  all negative values, and z for all positive values of z:
  #+attr_html: :width 300px :float nil: 
  [[../img/relu.png]]

  [[../img/relu2.png]]

- ReLU is the most commonly used activation function.
  #+begin_quote
  The original functions used were sigmoid functions (like for
  logistic regression, since 1969). ReLUs came back in the 2010s.

  *Pro:* quick to implement, derivative is one for all z \ge 0, which
  contributes to the stability of training in neural networks
  ("vanishing gradient feature").

  *Con:* derivative is zero for all z \lt 0, which switches nodes off for
  good during training ("dying ReLU problem").
  #+end_quote

* PRACTICE ReLU for the linear model

- Write the model equation for the D=1 case (one hidden unit)
  #+begin_quote
  y = f[x,\phi] = \phi_0 + \phi_1 a[\theta_10 + \theta_11 x]

  Four parameters: \phi_0, \phi_1, \theta_10, \theta_11.
  #+end_quote

- What happens with the model when you use the activation function?
  #+begin_quote
  Without activation (a[z]=z always): y = \phi_0 + \phi_1(\theta_10+\theta_11 x)
  = (\phi_0+\phi_1 \theta_10) + (\phi_1 \theta_11)x - just a straight line.

  With ReLU, the unit switches off/on depending on the sign of the
  pre-activation, so the model becomes *piecewise linear* with one
  kink at x* = -\theta_10/\theta_11 (where 0_10 + \theta_11 x = 0):

  - Off (\theta_10+\theta_11 x < 0): a[.]=0, so y = \phi_0 (flat, slope 0)
    
  - On (\theta_10+\theta_11 x >= 0): a[.]=identity, so
    y = (\phi_0+\phi_1\theta \theta_10) + (\phi_1\theta \theta_11)x (sloped)

  Continuous at the kink (no jump), but the slope changes abruptly
  there - one hidden unit buys exactly one bend.
  #+end_quote

- Compute this for a simple dataset and visualize it: \phi_0=0, \phi_1=2,
  \theta_10=-1, \theta_11=1 -> kink at x*=1.
  #+begin_quote


  | x | -1 | 0 | 0.5 | 1 | 1.5 | 2 | 3 |
  | y |  0 | 0 |   0 | 0 |   1 | 2 | 4 |

  Flat at 0 up to x=1, then rises with slope 2 (intercept -2).
  #+end_quote

- To visualize, open a Jupyter notebook to code along:
  #+begin_src python :file ../img/reluplot.png :results file graphics output :exports both :session *Python* :python python3 
    import numpy as np
    import matplotlib.pyplot as plt

    def relu(z):
        return np.maximum(0, z)

    def y(x, phi0, phi1, theta10, theta11):
        return phi0 + phi1 * relu(theta10 + theta11 * x)

    x = np.linspace(-2, 4, 100)
    plt.plot(x, y(x, phi0=0, phi1=2, theta10=-1, theta11=1))
    plt.xlabel('x'); plt.ylabel('y')
    plt.title('D=1 shallow network: one ReLU')
    plt.savefig("reluplot.png")
  #+end_src

* Supervised learning with NNs

- The ideas from supervised learning (training, inference) carry over:

  1) If we know the function parameters \phi, we can perform inference
     (predict y) by evaluating the equation for a given input x.

  2) Given a training dataset (x_i, y_i), we can define a least squares
     loss function L[\phi] and use it to measure how effectively the
     model approaches the dataset for a given parameter set.

  3) To train the model, we search for the parameter values that
     minimize the loss.

* Neural network intuition = Why does this work?

An NN represents a family of continuous piecewise linear functions
with up to D+1 linear regions:

- *piecewise*: the function is built from separate formulas, each valid
  only on its own interval. Our D=1 example has two (D+1) pieces.

- *linear*: within each piece, the formula is a straight line. Both the
  flat ("off") and the rising ("on") branch are straight lines.

- *continuous*: the pieces meet exactly at the seam, without jumps. At
  the kink x = x*, both formulas evaluate to the same y (example: \phi_0).

In the D=3 example, we have four (D+1) linear regions/pieces - here
shown for three different sets of \phi, all defined by equation [[NN]].

[[../img/piecewise.png]]

The intermediate quantities in the formula are called *hidden units*:
#+attr_html: :width 200px :float nil: 
[[../img/hidden.png]]

The input to a hidden unit is called a *preactivation* (z), and the
output is called an *activation* (a[z]). Our output function becomes:
#+attr_html: :width 300px :float nil: 
[[../img/function.png]]

You can visualize the flow of computation:

1) *Preactivation:* compute three linear functions (for sample \theta values)
#+attr_html: :width 800px :float nil: 
[[../img/preactivation.png]]

2) *Activation*: pass through ReLU functions (for sample \phi values)
#+attr_html: :width 800px :float nil: 
[[../img/activation.png]]

3) *Contribution to output*: weigh the hidden units
#+attr_html: :width 800px :float nil: 
[[../img/weights.png]]

The *input-side activation* function moves the joint/kink, while the
*output-side weights* can only change the slope of the "on" branch.

4) Construct the shallow neural network with one input, three hidden
   units, and one output:
   #+begin_src python :results none :session *Python* :python python3
     # Define a shallow neural network with, one input, one output, and three hidden units
     def shallow_1_1_3(x, activation_fn, phi_0,phi_1,phi_2,phi_3, theta_10, theta_11, theta_20, theta_21, theta_30, theta_31):
       pre_1 = theta_10 + theta_11 * x
       pre_2 = theta_20 + theta_21 * x
       pre_3 = theta_30 + theta_31 * x

       # Pass these through the ReLU function to compute the activations
       act_1 = ReLU(pre_1)
       act_2 = ReLU(pre_2)
       act_3 = ReLU(pre_3)

       # Weight the activations using phi1, phi2 and phi3
       w_act_1 = phi_1 * act_1
       w_act_2 = phi_2 * act_2
       w_act_3 = phi_3 * act_3

       # Combine the weighted activations and add the offset phi_0 to create the output
       y = phi_0 + w_act_1 + w_act_2 + w_act_3

       # Return everything we have calculated
       return y, pre_1, pre_2, pre_3, act_1, act_2, act_3, w_act_1, w_act_2, w_act_3
   #+end_src

* Depicting neural networks

- The image shows our example network with D=3 hidden
  units:
  #+attr_html: :width 800px :float nil:
  [[../img/depicting.png]]

- Computation flows from left to right: In image (a)
  
  1) Input is used to compute the hidden units h1, h2, h3, which are
     combined to compute the output y.

  2) All ten parameters are present and represented by edges/arrows.

  3) The orange lines are the bias/offset connections: Each orange
     circle labeled "1" is a fixed, constant input. The orange line
     from it to a node is that node's intercept parameter, drawn as if
     it was an ordinary weighted connection.

  4) The black lines are slopes.

  5) Each parameter multiplies its source and adds the result to its
     target: e.g. \phi_1 * h_1 is added to y; and we multiply \phi_0 by 1 (no
     effect) and add it to y.

  6) ReLU functions are applied at the hidden units.

- The offsets, ReLU functions, and parameter names are often
  omitted. Image (b) represents this simpler network.
